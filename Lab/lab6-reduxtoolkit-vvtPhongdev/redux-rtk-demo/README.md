# Redux Toolkit Demo — Lab 06

A step-by-step React implementation using **Redux Toolkit** and **React-Bootstrap** for styling.

## Features

1. **Counter**: Simple synchronous state using Redux slice actions (`increment`, `decrement`, `incrementByAmount`, `reset`).
2. **Todos**: Array-based state operations (`addTodo`, `toggleTodo`, `removeTodo`) with standard immer updates.
3. **Posts**: Asynchronous API requests fetching dummy data from JSONPlaceholder using `createAsyncThunk` and handling life cycles in `extraReducers`.

## Tech Stack

- **Framework**: React 19 + Vite
- **State Management**: Redux Toolkit & React-Redux
- **Styling**: React-Bootstrap & Bootstrap

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run local development server**:
   ```bash
   npm run dev
   ```

3. **Build the production bundle**:
   ```bash
   npm run build
   ```
